# Public website

Static pages required for Google Play: privacy policy, terms and a **public account deletion page**.
Generated by `npx tsx scripts/build-public-site.ts` from `apps/mobile/src/content/legal.ts` (single source with the in-app text).

Deploy `dist/` to any HTTPS static host at `https://adultingos.app` (or update the URLs in `apps/mobile/app.config.ts`).
Copy `dist/config.example.js` to `dist/config.js` and fill in the public Supabase URL and anon key.
Add `https://adultingos.app/delete-account` to Supabase Auth redirect URLs. The page verifies ownership with an e-mail sign-in link,
then calls the `delete-account` Edge Function.
