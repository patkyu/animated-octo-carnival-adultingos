# Public website

Static pages required for Google Play: privacy policy, terms and an account-deletion page.
Generated by `npx tsx scripts/build-public-site.ts` from `apps/mobile/src/content/legal.ts` (single source with the in-app text).
Plain HTML, relative links, no scripts or keys — works on any HTTPS static host, including under a sub-path.

Live (GitHub Pages, branch `gh-pages`):
- Privacy policy: https://patkyu.github.io/animated-octo-carnival-adultingos/privacy/
- Terms: https://patkyu.github.io/animated-octo-carnival-adultingos/terms/
- Account deletion: https://patkyu.github.io/animated-octo-carnival-adultingos/delete-account/

To update: rebuild, then publish `apps/web-public/dist` to the `gh-pages` branch (see `docs/deployment/public-site.md`).
Moving to your own domain: host `dist/` there, then change the URLs in `apps/mobile/app.config.ts`, `src/config/env.ts`, `SITE_URL` in `legal.ts` and Play Console.
