# Tester feedback template

Copy into an e-mail or the in-app feedback form. Don't include personal or ID numbers.

```
Tester ID / initials:
Date:
Phone model and Android version:
App version (Profile → About):

What were you trying to do?

What happened?

What did you expect?

Steps to reproduce (if a bug):
1.
2.
3.

How often? (always / sometimes / once)
Severity: (blocks me / annoying / cosmetic / suggestion)
Screenshot attached? (crop out personal info)

Anything confusing or delightful?
```
